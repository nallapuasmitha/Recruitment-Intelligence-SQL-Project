# Recruitment Intelligence SQL Project

## Project Overview
This project analyzes recruitment data using MySQL to understand hiring performance, recruiter productivity, and recruitment pipeline progress.

## Tools Used
- MySQL Community Server
- MySQL Workbench
- SQL

## Database Tables
- recruiters
- candidates
- jobs
- applications
- candidate_skills
- job_required_skills
- application_stage_history

## Key Analysis
1. Hiring rate by job
2. Recruiter performance analysis
3. Recruitment pipeline analysis
4. Recruitment database creation and data validation

## SQL Concepts Used
- SELECT statements
- JOINs
- LEFT JOIN
- Aggregate functions: COUNT, SUM, MIN, MAX
- GROUP BY
- ORDER BY
- CASE expressions
- Subqueries

## Project Structure
- `sql/` — SQL scripts for database setup and recruitment analysis
- `screenshots/` — screenshots of SQL queries and results
- `README.md` — project documentation

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open the SQL scripts in the `sql` folder.
3. Execute the scripts in the appropriate order.
4. Review the query results in MySQL Workbench.

## Conclusion
This project demonstrates how SQL can be used to organize recruitment data and analyze hiring rates, recruiter performance, and candidate progression through recruitment stages.
